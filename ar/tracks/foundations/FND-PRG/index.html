المسار الفرعي

FND-PRG البرمجة وممارسات تطوير البرمجيات

Programming and Software Practice

الغرض
تزويد خريجي التخصصات غير الحاسوبية بأساس متين في البرمجة وممارسات تطوير البرمجيات، وتحديث معارف خريجي الحاسب، قبل أن يبنوا أنظمة البيانات والذكاء الاصطناعي.
لمن هذا المسار
الخريجون والمنتقلون من مسارات مهنية أخرى ممن يتجهون إلى مقررات التحليل أو علم البيانات أو هندسة البيانات أو هندسة الذكاء الاصطناعي، وخريجو الحاسب الذين لم تشترط شهاداتهم الاختبار أو إدارة الإصدارات أو البيئات القابلة لإعادة الإنتاج.
الترتيب المقترح
يبدأ المسار الفرعي بالمقرر FND-PRG-101، ثم يُدرس المقرران FND-PRG-102 وFND-PRG-106 بالتزامن معه أو بعده مباشرة؛ ويليها المقررات FND-PRG-103 وFND-PRG-104 وFND-PRG-105، وهي تقود إلى المقرر DEV-SWE-201 وبقية المسارات الفرعية لمجموعة المطورين.
