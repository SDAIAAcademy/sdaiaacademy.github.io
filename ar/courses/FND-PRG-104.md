# FND-PRG-104 · اختبار البرمجيات ومراجعة الرموز البرمجية والتوثيق

Software Testing, Code Review and Documentation

- المسار: أساسيات البيانات والذكاء الاصطناعي
- المسار: [البرمجة وممارسات تطوير البرمجيات](../paths/FND-PRG.md)
- المستوى: المستوى 100 · الشرح
- الصيغة: دورة مكثفة: 4 أيام تدريبية ويوم للمشروع الختامي، مع عمل تحضيري موجه ومهمة متابعة متعقَّبة
- إجمالي الساعات: 30 ساعة
- الفئة المستهدفة: مبتدئ
- الحالة: قيد التطوير

## الوصف

يتسلم المشاركون مكتبة صغيرة غير مختبرة لتنظيف البيانات، ويجعلونها جديرة بالثقة. يكتبون اختبارات الوحدة واختبارات التكامل، ويصممون حالات الاختبار من المواصفات، ويعزلون الملفات والوقت واستدعاءات الشبكة بالتجهيزات (fixtures) وبدائل الاختبار (test doubles)، ويراجع بعضهم طلبات دمج بعض وفق قائمة تحقق، ويكتبون ملف README وتوثيقًا مرجعيًا، ويحزّمون المكتبة بحيث تُثبَّت وتجتاز اختباراتها في بيئة نظيفة. ويتناول المقرر DEV-SWE-204 لاحقًا اختبار الخصائص واختبار الطفرات والتحقق من الرموز البرمجية التي يكتبها الوكلاء.

## نواتج التعلم

بنهاية المقرر يستطيع المشارك أن:

- يميّز بين اختبارات الوحدة واختبارات التكامل واختبارات المسار من البداية إلى النهاية، ويشرح ما يستطيع كل منها إثباته وما لا يستطيع.
- يصمم حالات اختبار من المواصفات باستخدام فئات التكافؤ والقيم الحدية وحالات الخطأ.
- ينفذ اختبارات الوحدة واختبارات التكامل مع التجهيزات وبدائل الاختبار للملفات والوقت واستدعاءات الشبكة.
- يراجع طلب دمج من حيث الصحة والاختبارات وسهولة القراءة والأمن، ويكتب تعليقات قابلة للتنفيذ.
- يعدّ ملف README وتوثيقًا مرجعيًا، ويحزّم المكتبة للتثبيت.
- يسلّم إصدارًا مختبرًا ومراجَعًا وموثقًا مع فحوص آلية عند كل تغيير.

## الموضوعات

### ما الذي يُختبر

- الاختبارات بوصفها مواصفات قابلة للتنفيذ
- مستويات الاختبار وتكاليفها
- ما تخفيه نسبة التغطية

### تصميم الاختبارات

- فئات التكافؤ والقيم الحدية
- النصوص الفارغة والمفقودة والمختلطة الكتابة
- اختبارات الانحدار المستمدة من بلاغات الأخطاء

### أدوات الاختبار

- التجهيزات والاختبارات ذات المعاملات
- بدائل الاختبار للملفات والوقت والشبكة
- الاختبارات ضمن التكامل المستمر عند كل طلب دمج

### مراجعة الرموز البرمجية

- قوائم التحقق وطلبات الدمج الصغيرة
- تقديم التعليقات وتلقيها
- إخضاع الرموز البرمجية التي تولدها المساعدات الذكية للمعيار نفسه

### التوثيق والتحزيم

- ملف README ودليل البدء السريع
- سلاسل التوثيق والصفحات المرجعية المولدة
- الترقيم الدلالي للإصدارات وسجل التغييرات
- بناء حزمة وتثبيتها
