# FND-PRG-102 · سطر الأوامر وGit والبيئات القابلة لإعادة الإنتاج

Command Line, Git and Reproducible Environments

- المسار: أساسيات البيانات والذكاء الاصطناعي
- المسار: [البرمجة وممارسات تطوير البرمجيات](../paths/FND-PRG.md)
- المستوى: المستوى 100 · الشرح
- الصيغة: دورة مكثفة: 3 أيام تدريبية ويوم للمشروع الختامي، مع عمل تحضيري موجه ومهمة متابعة متعقَّبة
- إجمالي الساعات: 24 ساعة
- الفئة المستهدفة: مبتدئ
- الحالة: قيد التطوير

## الوصف

يُعدّ المشاركون عملًا يستطيع شخص آخر إعادة بنائه على جهاز نظيف. يكتبون برامج نصية لسطر الأوامر، ويستخدمون Git مع الفروع وطلبات الدمج والمراجعة في مستودع مشترك، ويحلّون تعارض دمج، ويثبّتون إصدارات التبعيات البرمجية، ويشغّلون مشروعًا في حاوية دون صلاحيات المسؤول، ويُبقون الأسرار خارج سجل الإيداعات.

## نواتج التعلم

بنهاية المقرر يستطيع المشارك أن:

- يشرح كيف يسجل Git التاريخ في صورة إيداعات وفروع ومستودعات بعيدة، وما الذي يغيّره كل أمر من الأوامر اليومية.
- يستخدم سطر الأوامر لفحص الملفات وتحويلها، بالجمع بين الأوامر بالأنابيب وبرنامج نصي قصير.
- يطبق مسار عمل يعتمد على الفروع وطلبات الدمج والمراجعة، بما في ذلك حل تعارض دمج.
- يهيئ بيئة معزولة ذات تبعيات مثبتة الإصدارات، ويشغّل المشروع في حاوية دون صلاحيات المسؤول.
- يعدّ مستودعًا يُبقي الأسرار خارج السجل، وينفذ إجراءات الاستجابة عند تسرب أحدها.
- يسلّم مستودعًا يعيد زميل إنتاجه على جهاز نظيف بالاعتماد على ملف README وحده.
