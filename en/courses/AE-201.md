## Description

Participants build and evaluate a tabular prediction model the way an engineer would ship it. On synthetic appointment data from a fictional clinic network they frame the prediction, prepare features inside a pipeline, set a baseline, move to regularised linear models and boosted trees, choose a validation scheme that matches time and patient grouping, find and remove planted leakage, pick metrics and a threshold from the cost of each error, analyse errors by slice, and compare two models with an interval rather than a single score. Every result is reproduced from a script with a fixed seed.

## Learning outcomes

By the end, the participant can:

- Distinguish random, grouped and time-ordered validation and state which one each described prediction task requires.
- Prepare a feature pipeline that imputes, encodes and scales inside cross-validation so that no statistic is computed on held-out rows.
- Implement a baseline, a regularised linear model and a gradient-boosted tree model and score each on the same validation splits.
- Analyse a dataset for target leakage and train-test contamination and remove each problem found.
- Compute ranking, threshold and calibration metrics and choose an operating threshold from a stated cost of each error type.
- Analyse errors by subgroup and slice to find where the model fails, then test one data or feature change aimed at the worst slice.
- Evaluate whether a challenger model beats the baseline using a paired comparison with a confidence interval and a stated minimum effect.

## Topics

### Framing a prediction task

- Target, unit and moment of prediction
- The decision the prediction serves
- Cost of each error type
- Rule-based and majority baselines

### Data preparation and features

- Missing values and imputation
- Encoding categories
- Scaling
- Date, lag and history features
- Pipelines that fit only on training folds
- Data checks before training
- Missingness indicators beside imputation
- Categories unseen in training, with a fixed feature-matrix shape at serving time

### Model families

- Linear and logistic regression with regularisation
- Decision trees
- Bagging and random forests
- Gradient boosting
- Bias and variance
- Hyperparameter search
- Feature importance and its limits

### Validation and leakage

- Holdout and k-fold
- Grouped and time-ordered splits
- Nested search
- Kinds of leakage
- Keeping a test set untouched

### Metrics and thresholds

- Confusion matrix, precision, recall and F1
- ROC and precision-recall curves
- Class imbalance and class weights
- Calibration
- Cost-based thresholds
- Regression metrics
- From logits to probabilities: sigmoid and softmax before a threshold
- Monthly forecasting per category: seasonal-naive baseline, time-ordered split and error per category

### Error analysis and comparison

- Slicing and subgroup error
- Bootstrap intervals
- Paired comparison of models
- Minimum effect of interest
- Multiple comparisons

### Reproducible results

- Seeds and locked environments
- Re-running from a clean clone
- A model card stub
