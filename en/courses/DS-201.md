## Description

Participants learn inference by computing it. On synthetic data from a fictional water utility whose true population is known, they draw repeated samples, build bootstrap intervals, run permutation tests beside classical ones, and report effect sizes with intervals instead of bare p-values. They see how testing 30 districts at once produces false findings and correct for it, then fit and read a first linear regression.

## Learning outcomes

By the end, the participant can:

- Explain what a sampling distribution, a standard error, a confidence interval and a p-value describe, and identify common misreadings.
- Compute bootstrap intervals for a mean, a median and a group difference, resampling the correct unit.
- Implement a permutation test, compare it with the matching classical test and report an effect size with an interval.
- Apply family-wise and false discovery rate corrections to many tests and measure the false findings without them.
- Analyse a linear regression of water consumption on household size and temperature, with slope intervals and residual checks.
- Deliver an inference brief that answers a manager's question with an estimate, an interval, a test, an effect size and stated limits.

## Format and days

### Day 1: Variation

- A sample is one draw of many
- Standard error by simulation and by formula
- Skew, outliers and the median
- Describing a sample honestly

### Day 2: Intervals

- The bootstrap idea
- Coverage is a testable claim
- Resample the right unit
- Intervals for differences and ratios

### Day 3: Tests

- A test is a shuffling rule
- p-values and their misreadings
- Effect size and practical significance
- Thirty districts, many false alarms

### Day 4: Regression and reporting

- Least squares as a summary
- Slopes with intervals
- Residuals and confounding
- Writing an inference brief

### Day 5: Capstone: the inference brief and its defence


## Topics

### Variation and estimation

- Population, sample, parameter and statistic
- Sampling distributions and standard error
- Skew, outliers and the median

### Bootstrap intervals

- Resampling the right unit
- Percentile intervals and coverage
- When the bootstrap fails

### Testing

- The null hypothesis as a shuffling rule
- Classical tests as approximations
- What a p-value is and is not
- Effect size, Type I and Type II errors

### Many comparisons

- Forking paths
- Family-wise error and false discovery rate
- Analysis plans written before the data

### A first regression

- Least squares and slope intervals
- Residual checks
- Confounding and a second variable
