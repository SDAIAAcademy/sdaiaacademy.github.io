# USE-SEC-210 · AI in Retail and Telecommunications

- Track: Data & AI Fluency
- Path: [AI in Sectors](../paths/USE-SEC.md)
- Level: Level 200 · Apply
- Format: Workshop: two days of eight sessions with labs, tracked pre-work and a defended map
- Total hours: 16 h
- Audience: practitioner
- Status: In development

## Description

Commercial, marketing, network and customer managers test forecasts, churn targeting, pricing rules, recommender results and network alerts against baselines and experiments, check customer-data use and build an opportunity-and-risk map for a synthetic retailer or operator. Individual marketing work is USE-PRO-210.

## Learning outcomes

By the end, the participant can:

- Explain how recommenders, forecasts, pricing, churn and network models each turn data into a decision.
- Compare a demand forecast with a naive seasonal baseline and state where the model earns its cost.
- Analyse a churn-retention campaign by uplift and estimate retained revenue and wasted offers.
- Test a personalised pricing rule for group differences and data used without consent.
- Measure a network anomaly detector against confirmed incidents and set an alert threshold the team can handle.
- Build an opportunity-and-risk map ranking use cases by measured value, customer harm and data rights.

## Prerequisites

- [USE-FLU-201 · Working with AI Assistants: Delegate, Describe, Judge, Own](USE-FLU-201.md)
- Knows how a retailer or operator prices, sells and serves; uses a spreadsheet

## Topics

### Retail uses

- Recommenders and search
- Demand forecasting

### Telecommunications uses

### Measuring value

- Baselines before models
- Offline metrics versus A/B tests
- Uplift and incremental value

### Customer data

- Consent for marketing and profiling
- Vulnerable customers and personalised prices
- Network location data
