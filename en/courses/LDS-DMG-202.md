# LDS-DMG-202 · Metadata, Catalogues and Lineage

- Track: Executives & Leaders
- Path: [Data Management and Governance Professions](../paths/LDS-DMG.md)
- Level: Level 200 · Apply
- Format: Workshop: two days with labs, plus a short follow-up task
- Total hours: 16 h
- Audience: practitioner
- Status: In development

## Description

Participants run an open-source catalogue over a fictional agency's synthetic database and file store. They harvest technical metadata, add what machines cannot (glossary terms, owners, classifications), measure how many machine-drafted descriptions need correction, judge a change through lineage and prepare records for a national or open catalogue.

## Learning outcomes

By the end, the participant can:

- Configure scheduled harvesting of technical metadata from a database and a file store.
- Prepare glossary terms and link them to columns, owners and classifications.
- Measure the error rate of machine-drafted asset descriptions under steward review.
- Analyse the downstream impact of a schema change using captured lineage.
- Prepare dataset records in a standard vocabulary for an external catalogue.

## Prerequisites

- [LDS-DMG-101 · Data Management Foundations](LDS-DMG-101.md)
- Reads a table schema and explains what each column holds

## Topics

### Metadata foundations

- Descriptive, structural and administrative metadata
- Dataset vocabulary standards

### Catalogue automation

- Connectors and scheduled harvesting
- Sample values: when to hide them
- Tag propagation
- Machine-drafted descriptions and review queues

### Glossary and lineage

- Definitions that settle disputes
- Approval and versioning
- Lineage as events from pipelines
- Column-level impact analysis

### The catalogue in operation

- Coverage, completeness and freshness
- Publishing to national and open catalogues
- The catalogue as context for AI assistants
