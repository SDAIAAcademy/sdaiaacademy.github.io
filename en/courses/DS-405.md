## Description

Participants run data preparation for the fictional Rimah Health Data Consortium: three hospital groups send encounter, laboratory and pharmacy extracts (about 30 million synthetic rows) for a readmission study, and a university partner wants a copy. They contract and link the producers, rebuild preparation as an incremental pipeline over partitioned columnar tables, generate and attack synthetic versions, compare privacy-enhancing methods for four requests, and write a release decision a privacy officer could sign. Single-table contracts come from DS-311; de-identification and basic differential privacy from DS-309.

## Learning outcomes

By the end, the participant can:

- Design shared data contracts, a pseudonymous linkage key and a breaking-change policy for a feed with several producers.
- Implement an incremental, idempotent preparation pipeline over partitioned columnar tables with quality gates.
- Evaluate a synthetic dataset for fidelity, analytical utility and disclosure risk.
- Compute differentially private statistics under a budget shared across repeated releases.
- Select a privacy-enhancing method for each data request by comparing protection, utility and cost.
- Decide whether to release a dataset and on what conditions, and defend the decision.

## Topics

### Contracts across producers

- Producer and consumer duties
- Code and unit harmonisation as contract clauses
- Keyed pseudonyms for record linkage
- Versions, deprecation and breaking changes

### Pipelines for large data

- Lazy columnar execution and partitions
- Idempotent, incremental loads
- Snapshots in open table formats
- Quality gates and lineage events

### Synthetic data

- What it is for and what it cannot do
- Relational generators
- Fidelity and fitness for the analysis
- Distance and membership-inference tests

### Privacy-enhancing methods and release

- Disclosure risk in longitudinal and linked records
- Privacy budgets across releases
- Federated analysis, secure aggregation and clean rooms
- Lawful basis, secondary use and release conditions
