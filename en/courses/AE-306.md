## Description

Participants build one batch pipeline end to end for Qafila, the fictional trading company of the Academy's data engineering course, whose margin report nobody trusts. They query raw extracts with analytical SQL, ingest an API and a database change feed incrementally, clean with dataframes, model a star schema with a slowly changing supplier dimension, write tested transformations and a data contract, orchestrate them, and land the result in an open table format that a second engine reads. Day four adds distributed processing, streaming and governance.

## Learning outcomes

By the end, the participant can:

- Analyse raw transactional extracts with analytical SQL, including window functions and incremental predicates.
- Implement incremental ingestion from an API and a change feed, keeping supplier history as a slowly changing dimension.
- Design a dimensional model at a stated grain and build it as tested, version-controlled transformations.
- Build an orchestrated pipeline with a data contract, quality gates, retries and backfills that fails safely when an upstream feed breaks.
- Configure an open table format with partitioning, schema evolution and time travel, and read it from a second engine.
- Classify every field under the national classification levels and apply minimisation, masking and access rules.

## Topics

### Platform shapes and analytical SQL

- Transactional and analytical systems; extract, load, transform (ELT)
- Lakehouse, layered refinement and columnar files

### Ingestion and change

- Schema drift and idempotent loads
- Change data capture (CDC), merge and slowly changing dimensions
- Single node first, distributed when measured

### Modelling, transformation and contracts

- Grain, facts and dimensions
- Tests, environments and state-aware builds
- Data contracts in an open standard
- Verifying agent-written transformations
- Backward-compatible contract changes: expand, migrate consumers with both fields in parallel, then contract

### Orchestration, scale and streaming

- Assets, retries and backfills
- Lineage as events
- Open table formats: snapshots, schema evolution, deletion vectors, compaction
- Logs and queues, delivery guarantees, watermarks

### Governance in the pipeline

- Classification levels; Restricted, which older texts call Confidential
- Minimisation and masking under the Personal Data Protection Law (PDPL)
- Erasure requests against history tables and snapshots
- National Data Management Office (NDMO) quality and architecture controls
