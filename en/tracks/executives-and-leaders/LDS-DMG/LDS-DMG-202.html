LDS-DMG-202 Metadata, Catalogues and Lineage

  • Level 200 · Apply
  • Workshop
  • 16 h
  • Audience: practitioner

Track

Executives & Leaders

Stream

LDS-DMG Data Management and Governance Professions

Level

Level 200 · Apply

Audience

practitioner

Format

Workshop: two days with labs, plus a short follow-up task

Total hours

16 h

Prerequisites

  • LDS-DMG-101 Data Management Foundations
  • Reads a table schema and explains what each column holds

Description

Participants run an open-source catalogue over a fictional agency's synthetic database and file store. They harvest technical metadata, add what machines cannot (glossary terms, owners, classifications), measure how many machine-drafted descriptions need correction, judge a change through lineage and prepare records for a national or open catalogue.

Learning outcomes

By the end, the participant can:

  1. Applied

    Configure scheduled harvesting of technical metadata from a database and a file store.

    Given a provided catalogue instance and synthetic sources.

    Evidence every table and file catalogued with schema and profile statistics.

  2. Applied

    Prepare glossary terms and link them to columns, owners and classifications.

    Given 30 columns and steward notes.

    Evidence 15 approved, linked terms.

  3. Applied

    Measure the error rate of machine-drafted asset descriptions under steward review.

    Given 40 drafts and a rubric.

    Evidence an accept, edit or reject log with the commonest error types.

  4. Applied

    Analyse the downstream impact of a schema change using captured lineage.

    Given lineage events and a change request.

    Evidence an impact note naming affected reports and owners, with a go or no-go.

  5. Applied

    Prepare dataset records in a standard vocabulary for an external catalogue.

    Given five catalogued datasets and the target's required fields.

    Evidence five records with licence and contact point that pass the target's validator.

Topics

Metadata foundations

  • Descriptive, structural and administrative metadata
  • Dataset vocabulary standards

Catalogue automation

  • Connectors and scheduled harvesting
  • Sample values: when to hide them
  • Tag propagation
  • Machine-drafted descriptions and review queues

Glossary and lineage

  • Definitions that settle disputes
  • Approval and versioning
  • Lineage as events from pipelines
  • Column-level impact analysis

The catalogue in operation

  • Coverage, completeness and freshness
  • Publishing to national and open catalogues
  • The catalogue as context for AI assistants

Tools and platforms

These are examples. Any equivalent tool may be used instead.

Open-source data catalogue
OpenMetadata, DataHub
Lineage events
OpenLineage with Marquez, the catalogue's built-in lineage
Dataset metadata vocabulary
W3C DCAT, Dublin Core
Language model for drafting
a locally served open-weight model, any approved hosted model

How the work is assessed

  • Supervised practical without AI assistance: three definitions and one lineage trace (25%)
  • Lab outputs (35%)
  • Health report and review (40%)
To pass
70% overall and at least 60% on the practical

Use of AI in the course

AI-off for the practical and first definitions; AI-full for generating the drafts under review; AI-tutor elsewhere.

AI-off: no AI assistance. AI-tutor: an assistant that hints and explains but does not give the answer. AI-full: any assistance; the participant owns the result and defends it.
