DEV-LLM-204 Document Intelligence: Parsing, Extraction and Multimodal Retrieval

  • Level 200 · Apply
  • Workshop
  • 16 h
  • Audience: practitioner

Track

AI Engineering

Stream

Level

Level 200 · Apply

Audience

practitioner

Format

Workshop: two days with labs and a short build project, with guided pre-work

Total hours

16 h

Prerequisites

  • DEV-LLM-201 Building Applications on Language Models
  • Validates model output against a schema in Python

Description

Participants turn scanned and digital documents into checked data. They compare parsers and vision models on Arabic and English pages, score parsing on its own, extract fields from forms and tables with validation rules, index page images beside parsed text, and send low-confidence fields to human review. The data is a synthetic set of tender forms, invoices and reports with tables, stamps and mixed scripts.

Learning outcomes

By the end, the participant can:

  1. Awareness

    Compare pipeline parsers, small document models and general vision-language models for layout, tables and Arabic text.

    Given five sample pages.

    Evidence a one-page selection note.

  2. Applied

    Measure parsing quality separately from extraction with edit distance and table-structure scores.

    Given 40 pages with reference transcriptions.

    Evidence a comparison by page type and language.

  3. Applied

    Implement schema-based extraction with field rules and cross-field checks.

    Given 100 synthetic forms.

    Evidence field accuracy and rejected records with reasons.

  4. Applied

    Implement retrieval that indexes page images alongside parsed text.

    Given 30 queries over pages with charts.

    Evidence recall with and without images.

  5. Performance

    Build a pipeline that routes low-confidence fields to human review.

    Given a target error rate.

    Evidence automation rate against error rate.

Topics

Parsing

  • Born-digital text layers versus scanned pages
  • Character recognition, layout and reading order
  • Right-to-left and mixed scripts
  • Specialised versus general vision models

Tables and forms

  • Table structure
  • Fields, checkboxes and stamps

Extraction with validation

  • Schemas and field rules
  • Cross-field checks
  • Confidence and abstention
  • Hidden text and instructions in documents

Retrieval and review

  • Page images as retrieval units
  • Human review queues and their cost

Tools and platforms

These are examples. Any equivalent tool may be used instead.

Document parsing
Docling, Unstructured, an open-weight document vision model
Character recognition with Arabic support
Tesseract, PaddleOCR
Vision-language model access
a locally served open-weight model, any commercial API
Image and text retrieval
colpali-engine, a vision-language embedding model with any vector index

How the work is assessed

  • Supervised check without AI assistance: score a parse against its reference and find extraction errors (15%)
  • Graded labs (45%)
  • Build project with defence (40%)
To pass
70% overall and a pass on the supervised check

Use of AI in the course

AI-off for the supervised check. AI-tutor in the labs. AI-full in the build project, which the participant defends live.

AI-off: no AI assistance. AI-tutor: an assistant that hints and explains but does not give the answer. AI-full: any assistance; the participant owns the result and defends it.
