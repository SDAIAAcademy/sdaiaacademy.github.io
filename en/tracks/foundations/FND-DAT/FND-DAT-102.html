FND-DAT-102 Data Wrangling with DataFrames

  • Level 100 · Explain
  • Intensive
  • 30 h
  • Audience: beginner

Track

Data & AI Foundations

Stream

FND-DAT Data Handling

Level

Level 100 · Explain

Audience

beginner

Format

Intensive: 4 teaching days and a capstone day, with guided pre-work and a tracked follow-up task

Total hours

30 h

Prerequisites

  • Writes short Python programs with functions, lists and dictionaries (FND-PRG-101 or equivalent)
  • Runs a notebook and installs a package in a provided environment

Description

Participants turn messy raw files into analysis-ready tables with a DataFrame library. They type data, handle missing values, parse dates, normalise Arabic and English text, reshape between wide and long forms, join with cardinality checks and aggregate, writing each step as a small tested function in a notebook that reruns from the raw files. Labs use a synthetic bilingual service-request register; the capstone documents a fresh extract.

Learning outcomes

By the end, the participant can:

  1. Awareness

    Describe tidy data and identify the reshaping operation that makes a given table tidy.

    Given five untidy tables.

    Evidence supervised AI-off check, four of five correct.

  2. Awareness

    Distinguish the ways data can be missing and explain how dropping, filling or flagging changes a summary.

    Given a register with missing values of known cause.

    Evidence a note comparing one summary under three treatments.

  3. Applied

    Implement a cleaning pipeline as chained, tested functions for types, dates, duplicates and categories.

    Given the raw register in three files.

    Evidence a notebook that runs from the raw files with passing assertions.

  4. Applied

    Apply joins with declared cardinality and reconcile row counts before and after each join.

    Given lookup tables and a file with duplicate keys.

    Evidence a join log explaining every row-count difference.

  5. Applied

    Normalise Arabic and English text fields for matching and measure the effect on match rates.

    Given bilingual names and addresses with labelled matches.

    Evidence a before-and-after table of correct and false matches.

  6. Awareness

    Identify defects in assistant-written wrangling code, such as wrong types, dropped rows and many-to-many joins.

    Given three assistant-written notebooks.

    Evidence a verification note with a check that exposes each defect.

Topics

Loading and typing

  • Delimited, spreadsheet and columnar files
  • Spreadsheet traps: serial dates, leading zeros, merged headers
  • Nullable, string and categorical types
  • Copy behaviour and method chaining

Cleaning

  • Missing values: causes and treatments
  • Duplicates and keys
  • Range and plausibility checks
  • Dates, periods, and Hijri and Gregorian calendars

Text, including Arabic

  • String methods and regular expressions
  • Arabic letter variants, diacritics, elongation and digit forms
  • Names and addresses across scripts

Reshaping, joining and aggregating

  • Tidy data, melt and pivot
  • Joins with validated cardinality
  • Group-by and window-style operations
  • Eager and lazy engines

Reproducible notebooks

  • Rerunning from raw files
  • Functions, assertions and parameters
  • Data dictionaries and cleaning logs

Tools and platforms

These are examples. Any equivalent tool may be used instead.

DataFrame library
pandas, Polars
Notebook environment
JupyterLab, marimo
Text processing
Python re and unicodedata modules, ICU libraries
Checks on DataFrames
Pandera, plain assertions
Hint-only tutor
an open-weight model in tutor mode, an approved assistant with a tutor instruction

How the work is assessed

  • Lab notebooks, test-checked (30%)
  • Supervised AI-off check (25%)
  • Capstone table, dictionary and log, rubric-scored (35%)
  • Live rerun (10%)
To pass
70% overall and at least 60% on the supervised check

Use of AI in the course

AI-off in the pre-work, first lab attempts and the supervised check. AI-tutor for the rest of the labs. AI-full in the capstone and the verification exercise, with every assisted step covered by a check.

AI-off: no AI assistance. AI-tutor: an assistant that hints and explains but does not give the answer. AI-full: any assistance; the participant owns the result and defends it.
