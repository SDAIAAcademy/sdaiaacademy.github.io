FND-AIC-102 How Language Models Work

  • Level 100 · Explain
  • Workshop
  • 16 h
  • Audience: beginner

Track

Data & AI Foundations

Stream

FND-AIC AI Concepts and Responsible Practice

Level

Level 100 · Explain

Audience

beginner

Format

Workshop: two days with labs and a tracked follow-up task

Total hours

16 h

Prerequisites

  • Runs a Python notebook and edits short scripts (FND-PRG-101 or equivalent)

Description

Participants test language model behaviour with small logged experiments. They count Arabic and English tokens, read next-token probabilities from a small open-weight model, vary sampling, probe long-context recall, write a minimal tool-calling loop and measure what extra reasoning effort buys. The output is a behaviour sheet for one model, each claim backed by a run.

Learning outcomes

By the end, the participant can:

  1. Awareness

    Explain how a model generates text by repeated next-token prediction and how sampling settings change the output.

    Given probability tables for three prompts.

    Evidence predictions checked against 20 logged samples per setting.

  2. Applied

    Measure token counts for parallel Arabic and English text across two tokenisers.

    Given parallel text with names, numbers and dates.

    Evidence a tokens-per-word table with cost and context implications.

  3. Awareness

    Describe how pretraining, post-training and reasoning effort shape an assistant's answers, and what a knowledge cut-off limits.

    Given a model card and the participant's reasoning-effort runs.

    Evidence a labelled lifecycle diagram and a note on what extra effort cost and bought.

  4. Applied

    Implement a minimal tool-calling loop and mark which steps the model and the program each perform.

    Given a model endpoint, a calculator and a search stub.

    Evidence a working script with its annotated log.

  5. Awareness

    Identify typical failure modes in model transcripts and name a check that catches each.

    Given ten transcripts showing fabrication, outdated facts, lost context, sycophancy and injected instructions.

    Evidence a classification sheet, at least eight of ten correct.

Topics

Tokens and prediction

  • Tokenisers and Arabic script
  • Transformers and attention in outline
  • Next-token probabilities and sampling
  • Tokens as cost and context

How models are made

  • Pretraining and post-training
  • Reasoning effort and test-time compute
  • Knowledge cut-off

Context and tools

  • Context windows and recall
  • Tool calls that a program executes
  • Retrieval as fresh context

Failure modes

  • Fabrication and sycophancy
  • Injection through retrieved text
  • Jagged capability

Tools and platforms

These are examples. Any equivalent tool may be used instead.

Open-weight model runtime, local or hosted
llama.cpp, Ollama, a provided hosted endpoint
Tokeniser library
Hugging Face tokenizers, tiktoken

How the work is assessed

  • Supervised AI-off scenario check (30%)
  • Lab notebooks with logged runs (30%)
  • Behaviour sheet (40%)
To pass
60% overall and at least 50% on the scenario check

Use of AI in the course

AI-off for the scenario check and the first two labs; AI-tutor for code in the other labs; AI-full for the behaviour sheet, whose claims must cite the participant's own runs.

AI-off: no AI assistance. AI-tutor: an assistant that hints and explains but does not give the answer. AI-full: any assistance; the participant owns the result and defends it.
