FND-AIC-101 How Machine Learning Works

  • Level 100 · Explain
  • Intensive
  • 30 h
  • Audience: beginner

Track

Data & AI Foundations

Stream

FND-AIC AI Concepts and Responsible Practice

Level

Level 100 · Explain

Audience

beginner

Format

Intensive: 4 teaching days and a capstone day, with guided pre-work and a tracked follow-up task

Total hours

30 h

Prerequisites

  • FND-PRG-101 Python Programming for Data and AI
  • Writes short Python functions and loops; a passed placement exercise is accepted instead of FND-PRG-101
  • Uses school algebra; the derivative of a squared error is taught in the pre-work

Description

Participants work out how supervised learning turns labelled examples into predictions, by hand first and then in code. They fit a nearest-neighbour rule and a linear model on paper, make a model overfit on purpose, choose a decision threshold from error costs and base rates, and hunt leaks seeded in a pipeline. Labs run on a laptop with small public or synthetic tabular data, and the capstone is an honest modelling report with a model card, defended in person.

Learning outcomes

By the end, the participant can:

  1. Awareness

    Explain how a supervised learner fits a prediction rule by minimising a loss.

    Given a ten-row table and a one-feature linear model.

    Evidence a hand-worked loss and two gradient steps, with a three-sentence explanation.

  2. Awareness

    Distinguish training, validation and test data, and identify overfitting and underfitting from plotted curves.

    Given six complexity and learning curves.

    Evidence a diagnosis and remedy per curve, at least five of six correct.

  3. Awareness

    Identify target, duplicate, preprocessing and temporal leakage in modelling pipelines.

    Given eight short pipeline descriptions.

    Evidence each leak named with its fix, at least six of eight correct.

  4. Applied

    Implement a train, validate and test workflow comparing a baseline, a linear model and a decision tree.

    Given a tabular dataset and a starter notebook.

    Evidence a notebook that runs end to end with a fixed seed and reports held-out metrics.

  5. Applied

    Compute confusion-matrix metrics and choose a threshold from error costs and the base rate.

    Given test-set scores and a cost per error type.

    Evidence a metrics table and a justified threshold.

  6. Applied

    Draft a one-page model card with intended use, data, metrics by subgroup and known limits.

    Given the participant's capstone model.

    Evidence a model card reviewed in the defence.

Topics

Learning from examples

  • Features, labels and prediction rules
  • Loss and gradient descent
  • Nearest neighbours and linear models by hand

Generalisation

  • Training, validation and test sets
  • Model complexity, overfitting and regularisation
  • Cross-validation and learning curves

Measuring a model

  • Confusion matrix, precision and recall
  • Thresholds, error costs and base rates
  • Regression errors against a naive baseline

Data and leakage

  • Encoding, scaling and missing values
  • Pipelines fitted on training data only
  • Target, duplicate and temporal leakage

Model families and limits

  • Trees, linear models and small neural networks
  • Distribution shift and subgroup error gaps
  • Where language models fit (FND-AIC-102)

Tools and platforms

These are examples. Any equivalent tool may be used instead.

Notebook environment
JupyterLab, a free hosted notebook service
Machine learning library
scikit-learn, tidymodels in R
Dataframes and plotting
pandas with Matplotlib, Polars with seaborn

How the work is assessed

  • Supervised check without devices: a hand fit, curve reading and leak spotting (30%)
  • Graded labs (30%)
  • Capstone with defence (40%)
To pass
60% overall and at least 50% on the supervised check

Use of AI in the course

AI-off for the hand fits, the first attempt at each lab and the supervised check. AI-tutor for debugging in the labs. AI-full for capstone code, which the participant explains in the defence.

AI-off: no AI assistance. AI-tutor: an assistant that hints and explains but does not give the answer. AI-full: any assistance; the participant owns the result and defends it.
