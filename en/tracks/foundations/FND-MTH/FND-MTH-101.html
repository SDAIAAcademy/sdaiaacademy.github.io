FND-MTH-101 Linear Algebra for Machine Learning

  • Level 100 · Explain
  • Extended
  • 45 h
  • Audience: beginner

Track

Data & AI Foundations

Stream

FND-MTH Mathematics and Statistics

Level

Level 100 · Explain

Audience

beginner

Format

Extended: 8 weeks part-time, one session and one lab a week, weekly graded problem sets and a capstone

Total hours

45 h

Prerequisites

  • School algebra: solving equations and reading graphs of functions
  • Writes short Python programs with lists, loops and functions (FND-PRG-101 or equivalent)

Description

Participants compute each idea of linear algebra twice: by hand on small cases and in array code on real data. They treat data as vectors, matrices as transformations, least squares as projection, and eigen and singular value decompositions as ways to find structure. Labs use public embeddings and images and a synthetic link graph. The capstone is a low-rank analysis of a public dataset, defended orally.

Learning outcomes

By the end, the participant can:

  1. Awareness

    Explain the geometric meaning of vectors, dot products, norms, projections and matrix products.

    Given two- and three-dimensional examples.

    Evidence supervised AI-off test, at least 70% correct.

  2. Awareness

    Describe what rank, eigenvalues and singular values reveal about a matrix and name one machine learning use of each.

    Given covariance and data matrices.

    Evidence written answers marked against a rubric.

  3. Awareness

    Identify ill-conditioned or rank-deficient systems and explain their effect on a least-squares fit.

    Given five numerical cases.

    Evidence a diagnosis sheet correct on four of five.

  4. Applied

    Compute products, inverses, projections and decompositions by hand for small matrices and in array code for large ones.

    Given the weekly problem sets.

    Evidence notebooks in which hand and code results agree within tolerance.

  5. Applied

    Implement least squares through QR factorisation and compare it with the normal equations.

    Given synthetic data with nearly collinear features.

    Evidence a notebook comparing residuals and condition numbers, with the difference explained.

  6. Applied

    Apply the singular value decomposition to build low-rank approximations and principal components.

    Given a public image, ratings or embedding matrix.

    Evidence the capstone notebook with error by rank and an interpretation of the leading components.

Topics

Vectors and similarity

  • Vectors as data points and directions
  • Dot product, norms and cosine similarity
  • Embeddings and distance in high dimensions
  • Attention scores as a matrix of dot products

Matrices as transformations

  • Matrix products as composition of maps
  • Span, independence, basis and rank
  • Linear systems
  • Counting floating-point operations (FLOPs) and memory

Orthogonality and least squares

  • Orthogonal projection
  • QR factorisation
  • Least squares, normal equations and conditioning

Eigenvalues and singular values

  • Eigenvectors of symmetric matrices
  • Covariance and principal component analysis (PCA)
  • Power iteration and link ranking
  • Singular value decomposition (SVD) and low-rank structure in recommenders and model adaptation

Working numerically

  • Vectorisation and broadcasting
  • Floating-point limits
  • Checking code against hand computation

Tools and platforms

These are examples. Any equivalent tool may be used instead.

Array computing
NumPy, SciPy, JAX
Notebook environment
JupyterLab, marimo, a free hosted notebook service
Problem-set checking
nbgrader, pytest
Hint-only tutor
an open-weight model in tutor mode, an approved assistant with a tutor instruction

How the work is assessed

  • Weekly problem sets, auto-checked (20%)
  • Two supervised AI-off tests, on paper and at the keyboard (40%)
  • Capstone notebook, rubric-scored (30%)
  • Oral check (10%)
To pass
60% overall and at least 50% on each supervised test

Use of AI in the course

AI-off for first attempts at problem sets and in both tests. AI-tutor in labs, giving hints without answers. AI-full in the capstone, which is defended orally.

AI-off: no AI assistance. AI-tutor: an assistant that hints and explains but does not give the answer. AI-full: any assistance; the participant owns the result and defends it.
