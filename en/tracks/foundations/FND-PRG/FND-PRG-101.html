FND-PRG-101 Python Programming for Data and AI

  • Level 100 · Explain
  • Extended
  • 60 h
  • Audience: beginner

Track

Data & AI Foundations

Stream

FND-PRG Programming and Software Practice

Level

Level 100 · Explain

Audience

beginner

Format

Extended: 12 weekly three-hour sessions with labs, graded assignments and a final project

Total hours

60 h

Prerequisites

  • No programming experience assumed

Description

Participants write Python from first principles and learn to read it as carefully as they write it. Each week opens with an AI-off tracing drill, then a lab on one synthetic dataset of municipal service requests in comma-separated values (CSV) and JavaScript Object Notation (JSON) files. The labs grow into a small command-line program that loads, validates, summarises and reports on the data, built from typed functions, classes and modules rather than one long notebook.

Learning outcomes

By the end, the participant can:

  1. Awareness

    Read a short program and state its output and the value of each variable at marked lines.

    Given printed programs of 10 to 30 lines, without a computer.

    Evidence supervised tracing checks with at least 80% correct.

  2. Awareness

    Distinguish lists, tuples, dictionaries and sets by mutability, ordering and lookup cost, and name the right one for a task.

    Given eight short task descriptions.

    Evidence a choice table with reasons, matching the reference on six of eight rows.

  3. Awareness

    Explain when work belongs in a notebook and when in a script or module, including the risk of hidden state.

    Given a notebook that gives different results when re-run from the top.

    Evidence a written diagnosis and a script that runs cleanly from a fresh interpreter.

  4. Applied

    Implement functions with type hints, docstrings and explicit handling of invalid input.

    Given a specification of a cleaning step and a file of messy records.

    Evidence functions that pass the provided checks and a static type check.

  5. Applied

    Use classes, files and the standard library to read, transform and write delimited and JSON data, including Arabic text.

    Given the synthetic service-request dataset.

    Evidence a module whose output files match the expected outputs.

  6. Performance

    Build a small command-line program that loads, validates, summarises and reports on a dataset, and explain its structure.

    Given a brief and a synthetic dataset not seen in class.

    Evidence a repository with a README and a sample run, and a walkthrough in which the participant changes one function live.

Topics

Values, names and control flow

  • Types, operators and expressions
  • Names, references and mutation
  • Conditionals and loops
  • Tracing a program by hand

Functions and modules

  • Parameters, return values and scope
  • Decomposing a task into small functions
  • Modules and the standard library
  • Docstrings and type hints

Collections and iteration

  • Lists, tuples, dictionaries and sets
  • Comprehensions and generators
  • Sorting with keys and grouping

Files, errors and text

  • Text, delimited and JSON files
  • Encodings and Arabic text
  • Exceptions, validation and failing loudly
  • Reading tracebacks

Program structure and habits

  • Classes and data classes
  • Notebooks versus scripts and modules
  • A command-line entry point
  • Committing to a course repository
  • Using an AI tutor without handing over the thinking

Tools and platforms

These are examples. Any equivalent tool may be used instead.

Python runtime and notebooks
CPython with JupyterLab, a free hosted notebook service
Code editor
Thonny, VSCodium or VS Code
Type checking and linting
mypy, Pyright, Ruff
Tracing visualiser
Python Tutor, the editor's step debugger

How the work is assessed

  • Supervised AI-off tracing and short coding checks in weeks 4, 8 and 11 (30%)
  • Weekly assignments (25%)
  • Final project on a rubric (25%)
  • Live walkthrough (20%)
To pass
60% overall, at least 60% on the supervised checks, and a passed walkthrough

Use of AI in the course

AI-off for tracing drills, the first in-session attempt at each lab and the supervised checks. AI-tutor (configured to hint, not solve) for weekly assignments and extensions. AI-full for the final project, which the participant explains and changes live.

AI-off: no AI assistance. AI-tutor: an assistant that hints and explains but does not give the answer. AI-full: any assistance; the participant owns the result and defends it.
