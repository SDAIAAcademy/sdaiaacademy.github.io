SPC-MOD-308 Graph, Network and Relational Data Analysis

  • Level 300 · Develop
  • Workshop
  • 16 h
  • Audience: practitioner

Track

Data Science

Stream

SPC-MOD Machine Learning and Modelling

Level

Level 300 · Develop

Audience

practitioner

Format

Workshop: two days with labs, guided pre-work and a tracked follow-up task

Total hours

16 h

Prerequisites

  • SPC-MOD-201 Machine Learning for Tabular Data: Baselines and Validation
  • Reads a matrix as an adjacency or similarity table
  • Has trained a small neural network, or completes the pre-work notebook

Description

Participants build networks from event data and analyse them with methods whose assumptions they can state. They choose nodes, edges, weights and time windows, compare centrality and clustering with null models, test whether detected communities are real, and predict links with a time-respecting split, ending with a small graph neural network set against simple heuristics. Data are public research networks and a synthetic supplier and payment ledger.

Learning outcomes

By the end, the participant can:

  1. Applied

    Construct a network from transaction records, justifying node, edge, weight and window choices.

    Given a synthetic payment ledger.

    Evidence a graph file and a note on how two alternative choices change the measures.

  2. Applied

    Compute centrality, clustering and assortativity against a degree-preserving null model.

    Given the constructed network.

    Evidence each measure reported beside its null distribution.

  3. Performance

    Evaluate community structure across two methods, under resampling and against external attributes.

    Given a public collaboration network.

    Evidence a report separating stable communities from artefacts of method or resolution.

  4. Performance

    Build and compare heuristic, embedding and graph neural network link predictors.

    Given a timestamped public network.

    Evidence ranking metrics with intervals on a later held-out period, with leakage checks.

  5. Awareness

    Explain how message passing generalises neighbourhood features and when engineered features suffice.

    Given a worked node-classification example.

    Evidence a written answer in the supervised check.

Topics

From records to networks

  • Nodes, edges, weights and direction
  • Bipartite projections and their distortions
  • Temporal networks and missing edges

Measures and null models

  • Centrality and what each measure assumes about flow
  • Clustering and assortativity
  • The configuration model

Community structure

  • Modularity and its resolution limit
  • Leiden and stochastic block models
  • Validation without ground truth

Link prediction and relational learning

  • Heuristics and node embeddings
  • Temporal splits and leakage
  • Message passing; knowledge graphs are in DEV-DAT-304

Tools and platforms

These are examples. Any equivalent tool may be used instead.

Network analysis
NetworkX, igraph, graph-tool
Network visualisation
Gephi, Cytoscape
Graph neural networks
PyTorch Geometric, a message-passing layer in plain tensor code

How the work is assessed

  • Supervised AI-off check on measures and assumptions (20%)
  • Graded labs (30%)
  • Capstone with live defence (50%)
To pass
70% overall and at least 60% on the capstone

Use of AI in the course

AI-off for the check and the construction lab. AI-tutor in the measurement and community labs. AI-full in link prediction and the capstone, defended live.

AI-off: no AI assistance. AI-tutor: an assistant that hints and explains but does not give the answer. AI-full: any assistance; the participant owns the result and defends it.
