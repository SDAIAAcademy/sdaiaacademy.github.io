SPC-ANL-202 Analysis with AI Assistants: Delegate, Verify, Reproduce

  • Level 200 · Apply
  • Workshop
  • 16 h
  • Audience: practitioner

Track

Data Science

Stream

SPC-ANL Analysis and Business Intelligence

Level

Level 200 · Apply

Audience

practitioner

Format

Workshop: two days with labs, guided pre-work and a peer-rerun project

Total hours

16 h

Prerequisites

  • SPC-ANL-201 Exploratory Analysis and Visualisation
  • Writes and debugs short dataframe or SQL analyses without assistance

Description

Participants analyse data with a coding agent in a notebook. They decide which steps to delegate, brief the agent with acceptance checks, and confirm results by recomputing key numbers another way. Each lab ends with a verification note: what the agent produced, how it was checked, what was wrong. They measure run-to-run variability and package an analysis that a peer reruns from logged prompts, code and data.

Learning outcomes

By the end, the participant can:

  1. Applied

    Prepare a delegation plan marking which steps stay with the analyst, and a brief stating question, data, constraints and acceptance checks.

    Given a twelve-step analysis plan and a synthetic customer-service dataset.

    Evidence a delegation table matching the reference on ten of twelve steps, the brief and the checks that passed.

  2. Applied

    Test assisted analyses by recomputing headline numbers and checking joins, filters and denominators.

    Given three analyses with seeded errors.

    Evidence a verification note per analysis.

  3. Applied

    Measure run-to-run variability by repeating one request and comparing code, numbers and conclusions.

    Given five runs of one question.

    Evidence a table of key numbers with their spread.

  4. Performance

    Deliver an assisted analysis package that another analyst can rerun and audit.

    Given a new question and a two-hour limit.

    Evidence a repository with code, data version, transcript log and verification note, rerun by a peer.

Topics

Delegation and briefing

  • Where agents fail on data work
  • What stays with the analyst: framing, causal claims, sign-off
  • Checks written before the run

Verification

  • Second-route recomputation
  • Row counts, cardinality and denominators
  • Agents that try many analyses and report one
  • Narrative checked against numbers

Reproducibility

  • Asking the same question several times
  • Logging prompts, model and transcripts
  • Pinned data versions and environments

Tools and platforms

These are examples. Any equivalent tool may be used instead.

Assistant or coding agent with notebook access
a local open-weight model, a hosted model, a commercial coding agent
Notebook and version control
Jupyter, marimo, Git

How the work is assessed

  • Supervised AI-off check: errors in a printed analysis (25%)
  • Lab verification notes (35%)
  • Capstone and peer rerun (40%)
To pass
70% overall, at least 60% on the supervised check, and a successful peer rerun

Use of AI in the course

AI-off for the supervised check and the seeded-error lab. AI-full elsewhere, since assisted work is the subject, with every delegated step logged.

AI-off: no AI assistance. AI-tutor: an assistant that hints and explains but does not give the answer. AI-full: any assistance; the participant owns the result and defends it.
