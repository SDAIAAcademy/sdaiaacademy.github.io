USE-PRO-203 AI for Finance, Accounting and Audit Work

  • Level 200 · Apply
  • Workshop
  • 12 h
  • Audience: practitioner

Track

Data & AI Fluency

Stream

USE-PRO Fluency for Professions

Level

Level 200 · Apply

Audience

practitioner

Format

Workshop: two days of labs on one synthetic case, plus a tracked baseline

Total hours

12 h

Prerequisites

  • USE-FLU-201 Working with AI Assistants: Delegate, Describe, Judge, Own
  • Knows double-entry bookkeeping, lookups and conditional sums; notebooks are prepared, so no coding is needed

Description

Participants close a synthetic organisation's month under one rule: figures come from formulas or code someone can re-run, never from an assistant's prose. They reconcile, repair a budget model, write cell-tied commentary and draw an audit sample.

Learning outcomes

By the end, the participant can:

  1. Awareness

    Distinguish figures computed by code or formulas from figures generated as text, and state the check each needs.

    Given six AI answers to finance questions.

    Evidence a classification matching the key on five of six.

  2. Applied

    Implement a bank-to-ledger reconciliation with generated code or formulas, proved by control totals.

    Given 1,200 synthetic lines with planted timing differences and duplicates.

    Evidence unmatched items and totals agreeing with the reference.

  3. Applied

    Test and repair a budget model with an assistant against hand-worked cases.

    Given a model with five seeded faults.

    Evidence a repaired model with a test per fix.

  4. Applied

    Draft variance commentary and a reproducible audit sample, leaving causes and exceptions to the person's judgement.

    Given 12 cost centres and 5,000 synthetic invoices.

    Evidence cell-matched commentary and a sampling file with method, seed and exceptions.

  5. Performance

    Redesign one recurring finance or audit task and measure time and errors before and after.

    Given a pre-work baseline and two AI-assisted runs.

    Evidence a redesign card defended in a live review.

Topics

Why language models get numbers wrong

  • Arithmetic in prose versus computed results
  • AI functions in cells that change on recalculation

Spreadsheets and generated code

  • Tracing precedents and dependants
  • Running and reading generated code
  • Test cases and change logs

Commentary, audit support and data rules

  • Variance explanations tied to cells
  • Documented sampling with recorded seeds
  • Scepticism towards AI output
  • Confidential and payroll data in approved tools

Tools and platforms

These are examples. Any equivalent tool may be used instead.

Assistant that runs code
an open-weight model with a local notebook, the code-execution mode of an approved assistant
Spreadsheet
LibreOffice Calc, Microsoft Excel
Prepared notebook
JupyterLab with pandas, a free hosted notebook service

How the work is assessed

  • Supervised AI-off check (20%)
  • Lab artefacts (40%)
  • Redesign card and live review (40%)
To pass
70% overall, with the reconciliation agreeing with the reference totals

Use of AI in the course

AI-off for the supervised check and hand-worked cases; AI-tutor while repairing the model; AI-full for generated code and the redesign, with every figure recomputed.

AI-off: no AI assistance. AI-tutor: an assistant that hints and explains but does not give the answer. AI-full: any assistance; the participant owns the result and defends it.
