USE-SEC-208 AI in Media and Creative Industries

  • Level 200 · Apply
  • Workshop
  • 16 h
  • Audience: practitioner

Track

Data & AI Fluency

Stream

USE-SEC AI in Sectors

Level

Level 200 · Apply

Audience

practitioner

Format

Workshop: two days of eight sessions with labs, tracked pre-work and a defended map

Total hours

16 h

Prerequisites

  • USE-FLU-201 Working with AI Assistants: Delegate, Describe, Judge, Own
  • Knows how content is commissioned, licensed and distributed; uses a spreadsheet

Description

Broadcast, publishing, studio and platform managers test dubbing, generation and moderation tools on Arabic and English material, check assets for consent, rights and provenance and build an opportunity-and-risk map for a synthetic media group. Individual editorial work is USE-PRO-205.

Learning outcomes

By the end, the participant can:

  1. Awareness

    Explain which rights, consents and labels each AI use in the media value chain needs.

    Given a synthetic production chain.

    Evidence an annotated chain matching the key.

  2. Applied

    Measure a machine dubbing and subtitling workflow for meaning, timing, names and dialect.

    Given a consented three-minute clip and a reference translation.

    Evidence a scored error sheet and a broadcast decision.

  3. Applied

    Test whether assets carry provenance data that survives common edits.

    Given ten generated and edited files.

    Evidence a provenance log with the label each needs.

  4. Applied

    Set a moderation threshold per dialect by weighing harm missed against lawful speech removed.

    Given 1,000 labelled synthetic comments.

    Evidence an error table by dialect and a review-queue size.

  5. Performance

    Build an opportunity-and-risk map ranking media AI uses by value, quality risk, rights exposure and audience trust.

    Given a synthetic media group profile.

    Evidence a one-page map defended in five minutes.

Topics

Uses

  • Script and asset generation
  • Dubbing, voice cloning and subtitling
  • Archive tagging and search
  • Moderation and recommendation

Arabic content

  • Standard Arabic and dialects
  • Names, numbers and diacritics
  • Right-to-left subtitles

Rights and provenance

  • Copyright in training data and outputs
  • Voice and likeness consent
  • Content credentials versus watermarks
  • Synthetic-media labelling duties

Moderation and mapping

  • Over-removal and appeals
  • Cost per finished minute
  • Pilot, scale or stop criteria

Tools and platforms

These are examples. Any equivalent tool may be used instead.

Speech recognition and synthesis in a free notebook
Whisper, an open-weight text-to-speech model, a commercial speech API
Provenance inspection
an open-source Content Credentials (C2PA) verifier, ExifTool
Spreadsheet
LibreOffice Calc, Microsoft Excel, Google Sheets

How the work is assessed

  • AI-off scenario check, ten cases (25%)
  • Lab records (35%)
  • Map and five-minute defence (40%)
To pass
70% overall and 60% on the AI-off check

Use of AI in the course

AI-off for the scenario check and dubbing scores. AI-tutor in the provenance, moderation and cost labs. AI-full for the map, defended live.

AI-off: no AI assistance. AI-tutor: an assistant that hints and explains but does not give the answer. AI-full: any assistance; the participant owns the result and defends it.
