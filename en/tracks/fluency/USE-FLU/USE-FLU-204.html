USE-FLU-204 Supervising AI Agents in Knowledge Work

  • Level 200 · Apply
  • Workshop
  • 16 h
  • Audience: practitioner

Track

Data & AI Fluency

Stream

USE-FLU Fluency for Everyone

Level

Level 200 · Apply

Audience

practitioner

Format

Workshop: two days of four sessions with labs, guided pre-work and a tracked agent task

Total hours

16 h

Prerequisites

  • USE-FLU-201 Working with AI Assistants: Delegate, Describe, Judge, Own
  • USE-FLU-202 also meets the prerequisite
  • Classifies work material before sharing it (USE-FLU-104)

Description

Participants hand multi-step work to an AI agent that acts on mail, files and calendars through connectors and on a schedule, and stay in charge. In a sandbox of synthetic data they brief the agent, grant permissions stepwise, gate irreversible actions, catch planted injections and review transcripts, then supervise a task of their own over two runs.

Learning outcomes

By the end, the participant can:

  1. Applied

    Prepare a delegation brief with goal, standing context, permitted sources, forbidden actions, stop conditions and result format.

    Given a synthetic weekly-report request.

    Evidence a brief meeting a seven-point checklist.

  2. Applied

    Configure least-privilege connector permissions and approval before every send, delete, payment or publication.

    Given a sandbox with mail, calendar and files.

    Evidence a run log where every irreversible action waited for approval.

  3. Applied

    Test an agent against hidden instructions and apply a stop, contain and report routine.

    Given documents with three planted injections, one inside an image.

    Evidence a findings note with a limiting permission change per attempt.

  4. Applied

    Analyse agent transcripts for skipped steps, invented facts, actions beyond the brief and unsupported claims of success.

    Given three runs with five planted faults.

    Evidence checklists catching at least four faults.

  5. Performance

    Design and supervise an agent task from the participant's own work and decide to keep, change or stop it.

    Given synthetic or anonymised material over two runs.

    Evidence a task folder of brief, permissions, logs and review notes, defended.

Topics

Choosing and briefing

  • Chat, fixed workflow or agent
  • Partial versus complete task success
  • Standing instructions, project files and skills

Permissions and approvals

  • Read, write and act scopes
  • Time-limited access and revocation
  • Scheduled and background runs

Security for the delegator

  • Hidden instructions in mail, pages, files and images
  • Untrusted content, private data and an outbound channel
  • Poisoned memory and standing context

Reviewing agent work

  • Reading a transcript step by step
  • Parallel agents and review time
  • Records of who approved what

Tools and platforms

These are examples. Any equivalent tool may be used instead.

Agent client with open-protocol connectors
an open-source agent client with Model Context Protocol (MCP) servers, the agent mode of an approved assistant
Sandbox mail and files
a local mail test server and shared folder, a provided office-suite test tenant
Scheduled runs
a self-hostable workflow tool such as n8n, the agent client's scheduler

How the work is assessed

  • Supervised AI-off transcript fault check (20%)
  • Lab artefacts (30%)
  • Capstone folder (25%)
  • Defence (25%)
To pass
70% overall, 60% on the AI-off check, and no unapproved irreversible action in the capstone logs

Use of AI in the course

AI-off for the transcript check and first review of each run; AI-tutor for the brief; AI-full in agent labs and the capstone, where the participant approves and owns every action.

AI-off: no AI assistance. AI-tutor: an assistant that hints and explains but does not give the answer. AI-full: any assistance; the participant owns the result and defends it.
